<analysis>**original_problem_statement:**
El usuario solicitó la creación de un sistema financiero integral para SOLES CORPORATIVO – CRÉDITOS. El sistema debe gestionar el ciclo completo de créditos, incluyendo la captura de clientes, gestión de créditos, asignación de cartera, cobranza, y cierres de caja.

**PRODUCT REQUIREMENTS:**
- **Autenticación y Roles (RBAC):** Implementar un sistema de login seguro con roles fijos (Desarrollador, Administrador, Gerente Regional, Supervisor, Asesor de Crédito), cada uno con permisos y vistas específicas. Los supervisores deben poder autorizar o rechazar créditos.
- **Gestión de Datos:** Manejar bases de datos para Clientes y Créditos con campos específicos.
- **Lógica de Cobranza:** El sistema debe calcular automáticamente los calendarios de pago para créditos diarios, semanales y catorcenales, omitiendo fines de semana para los diarios.
- **Evidencias Obligatorias:** Requerir fotos del cliente, domicilio y negocio, junto con coordenadas GPS, para poder procesar un crédito. Además, se requiere evidencia fotográfica al momento de desembolsar el dinero.
- **Estructura Jerárquica:**
    - **Zonas:** Las regiones (ej. Yajalón) actúan como sedes para comunidades subordinadas (ej. Chilón, Bachajón).
    - **Usuarios:** Los Gerentes/Admins asignan Supervisores a una región. Los Supervisores, a su vez, asignan Asesores a su equipo dentro de esa región.
- **Flujo de Cobranza y Caja:**
    - Los asesores tienen una caja individual para sus cobros diarios.
    - Se debe poder registrar un estado de NO PAGO o NO SE LOCALIZÓ con evidencia de contacto.
    - La caja del supervisor debe ser una caja regional que consolide los montos de sus asesores.
    - Las vistas de Cartera y Caja deben reflejar esta jerarquía (Personal para Asesor, Regional para Supervisor).
- **UI/UX:** Diseño minimalista y profesional con fondo gris, botones grandes, y colores específicos para estados (verde, amarillo, rojo) y branding (dorado/amarillo).

**User's preferred language**: Spanish
